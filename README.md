# Rowgaik
Flet-приложение для Android с картой кампуса МИИГАиК и расписанием занятий.

## Скачать

[Скачать последнюю версию](https://github.com/rowdyslav/Rowgaik/releases/latest/download/Rowgaik-latest.apk)

## Настройка расписания

Группа выбирается на сайте расписания, поэтому искать или вводить её ID вручную не нужно.

1. Откройте вкладку **Расписание** в нижнем меню.
2. В открывшемся расписании выберите нужную группу обычным нажатием внутри WebView.
3. Дождитесь загрузки расписания выбранной группы.
4. Зажмите кнопку **Расписание** в нижнем меню.

После долгого нажатия приложение возьмёт `groupId` из текущего URL и сохранит его на устройстве. При следующем запуске расписание откроется сразу для сохранённой группы.

Если группу ещё не сохраняли, используется группа `2050`.

## Карта и расписание

- Нажмите **Карта** или **Расписание** в нижнем меню, чтобы переключить вкладку.
- Ссылки на карту, открытые из расписания, перехватываются приложением и открываются во вкладке **Карта**.
- При таком переходе приложение автоматически переключает вкладку и показывает анимацию перехода.

## О проекте

Приложение открывает интерактивную карту кампуса МИИГАиК и веб-версию расписания в удобном мобильном интерфейсе.

Новые APK автоматически собираются через GitHub Actions и публикуются в разделе [Releases](https://github.com/rowdyslav/Rowgaik/releases).
